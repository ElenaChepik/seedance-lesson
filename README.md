## Публикация через сайт GitHub

1. Войдите в свой аккаунт на [GitHub](https://github.com/).
2. Откройте [создание репозитория](https://github.com/new). В поле **Repository name** введите `seedance-lesson` — либо другое имя латиницей без пробелов. Выберите **Public**, включите **Add a README file** и нажмите **Create repository**. Публичный репозиторий подходит для бесплатного GitHub Pages.
3. Откройте **Add file → Upload files** в созданном репозитории.
4. На компьютере откройте распакованный комплект до уровня, где видны `index.html`, `web` и `png`. Выделите **всё содержимое этой папки** и перетащите в область загрузки GitHub. Не загружайте ZIP и не перетаскивайте внешнюю папку целиком: `index.html` должен оказаться прямо в корне репозитория.
5. Дождитесь завершения загрузки. В сообщении к изменению напишите `Добавлена лекция`. Сохраните изменения в ветку **main** кнопкой **Commit changes**. README из комплекта заменит стартовый README.
6. Проверьте, что в корне есть файл **.nojekyll**. Если он не попал в загрузку, выберите **Add file → Create new file**, задайте имя `.nojekyll`, оставьте содержимое пустым и сохраните в `main`.
7. Перейдите в **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**. Укажите **Branch → main**, папку **/(root)** и нажмите **Save**.
8. Дождитесь завершения публикации. Статус можно увидеть во вкладке **Actions**, а адрес — в **Settings → Pages**, кнопка **Visit site**. Если адрес пока не появился, обновите страницу настроек спустя несколько минут.

Не нужны платный хостинг, установка библиотек или команды в терминале.

## Что загрузить

```text
корень репозитория/
├── .nojekyll
├── README.md
├── favicon.ico
├── index.html
├── web/
│   ├── seedance_2_5.html
│   ├── scene_timeline.html
│   └── shared.css
└── png/
    └── seedance_2_5/
        ├── 01_hero_process.png
        ├── 02_brief.png
        ├── 03_references.png
        ├── 04_timeline.png
        └── 05_acceptance.png
```

`index.html` — оглавление. Полная лекция находится в `web/seedance_2_5.html`.

В публичный комплект включены файлы сайта. Рабочие планы, скрипты сборки и исходный документ Word остаются в локальном проекте. Кнопка скачивания исходного Word в публичной копии убрана.

## Ссылка для слушателей

Если имя репозитория — `seedance-lesson`, адрес имеет вид:

```text
https://ВАШ_ЛОГИН_GITHUB.github.io/seedance-lesson/
```

Прямая ссылка на лекцию:

```text
https://ВАШ_ЛОГИН_GITHUB.github.io/seedance-lesson/web/seedance_2_5.html
```

Замените `ВАШ_ЛОГИН_GITHUB` на имя аккаунта GitHub, не на имя Telegram. Точный адрес всегда копируйте из **Settings → Pages**. При другом имени репозитория изменится соответствующая часть адреса.

## После публикации

- Откройте главную страницу и нажмите «Открыть лекцию».
- Убедитесь, что отображаются все пять картинок и работает увеличение.
- Переключите три интервала сцены и откройте демо на весь экран.
- Отметьте пункт чек-листа, обновите страницу: отметка должна сохраниться в этом браузере.
- Ответьте на вопрос квиза и проверьте ссылку «© Чепик Елена» внизу.
- Откройте страницу с телефона.

Отметки чек-листа хранятся только в браузере слушателя; между устройствами они не синхронизируются.

## Обновление

Загрузите изменённые файлы по тем же путям через **Add file → Upload files** и сохраните в `main`. GitHub Pages опубликует обновление автоматически. Ссылки на страницу останутся прежними. При замене картинок сохраняйте их имена и папки. Если видите старую версию, дождитесь завершения публикации и нажмите **Ctrl+F5**.

## Если что-то не открылось

- **404 на главной:** проверьте наличие `index.html` именно в корне и выбор `main` / `/(root)` в настройках Pages. После включения Pages дождитесь успешного завершения публикации.
- **Нет иллюстраций:** проверьте, что папка `png/seedance_2_5` загружена целиком, а имена файлов и регистр букв сохранены.
- **Нет демо:** проверьте файлы `web/scene_timeline.html` и `web/shared.css`.
- **В репозитории только ZIP:** распакуйте архив на компьютере и загрузите его содержимое. GitHub Pages не распаковывает ZIP в сайт.
- **Публикация завершилась ошибкой:** откройте последний запуск во вкладке **Actions** и посмотрите сообщение об ошибке.

Официальные инструкции: [загрузка файлов и папок](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository), [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
